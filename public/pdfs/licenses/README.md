# Lisenziya PDF Faylları

Bu qovluqda şirkətin lisenziya və sertifikat PDF faylları yerləşdirilməlidir.

## Faylların əlavə edilməsi:

1. PDF faylları bu qovluğa yükləyin
2. `resources/views/licenses.blade.php` faylında `licenses` array-ini yeniləyin
3. Hər lisenziya üçün thumbnail şəkli `public/images/licenses/` qovluğuna əlavə edin

## Nümunə fayl adları:
- insaat-lisenziyasi.pdf
- iso-9001.pdf
- iso-14001.pdf
- ohsas-18001.pdf
- vergi-sehadetnamesi.pdf
- dovlet-qeydiyyati.pdf

## Thumbnail şəkilləri:
Hər PDF üçün 300x400 piksel ölçüsündə thumbnail şəkli yaradın və `public/images/licenses/` qovluğuna yerləşdirin.
